# Inhibition Zone App

This repository contains the handoff version of the Inhibition Zone App for antibiotic inhibition-zone analysis.

## Included Components

- React + Vite + Capacitor frontend
- PHP API for application data
- Homography FastAPI service
- YOLO FastAPI service
- Android project for mobile deployment
- CLSI breakpoint CSV used for report S/I/R suggestions

## Quick Start

1. Clone the repository.
2. Run `git lfs pull`.
3. Open the app folder:
   `App tugas akhir/App tugas akhir/Biotechnology App Dashboard/Biotechnology App Dashboard`
4. Follow the full setup instructions in `RUN_FROM_START.md`.
